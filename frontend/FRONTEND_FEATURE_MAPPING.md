# Frontend Feature Mapping

This document maps all features from the frozen backend (v1.0.0) to their corresponding frontend UI screens and defines their API integration status.

## Core Modules

| Backend Feature | Frontend Screen | API Status |
| :--- | :--- | :--- |
| **Authentication** | Login Page (`/login`) | Connected |
| **Dashboard** | Admin Dashboard (`/admin`), Farmer Dashboard (`/farmer`), Buyer Dashboard (`/buyer`) | Pending |
| **Users** | User Management (`/admin/users`) | Pending |
| **Farmers** | Farmer Management (`/admin/farmers`) | Pending |
| **Products** | Product Catalog (`/products`), Product Details (`/products/:id`) | Pending |
| **Categories** | Category Management (`/admin/categories`) | Pending |
| **Orders** | Orders Page (`/orders`), Order Details (`/orders/:id`) | Pending |
| **Auctions** | Auctions Dashboard (`/auctions`) | Pending |
| **Payments** | Payments & Billing (`/payments`) | Pending |
| **Coupons** | Coupon Management (`/admin/coupons`) | Pending |
| **Reviews** | Reviews & Ratings Page (`/reviews`) | Pending |
| **Wishlist** | User Wishlist (`/wishlist`) | Pending |
| **Notifications** | Notifications Panel (`/notifications`) | Pending |
| **Delivery** | Delivery Tracking (`/delivery`) | Pending |
| **Analytics** | Analytics Dashboard (`/admin/analytics`) | Pending |
| **Activity Logs** | Activity Logs View (`/admin/activity`) | Pending |
| **Farmer Verification** | Verification Queue (`/admin/verifications`) | Pending |
| **Settings** | User Settings (`/settings`) | Pending |
